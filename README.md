# Dice Poker

A terminal dice-poker game with a dependency-free browser interface.

## Run the web interface

```powershell
.\dice_game_venv\Scripts\python.exe web_server.py
```

Open <http://127.0.0.1:8000> in your browser. Stop the server with `Ctrl+C`.

## Run the original terminal interface

```powershell
.\dice_game_venv\Scripts\python.exe DicePoker.py
```
