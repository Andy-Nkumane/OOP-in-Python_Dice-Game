# Dice Poker

The original Python terminal game, plus a standalone browser version.

## Browser game

Open `web/index.html` directly, or use the project's GitHub Pages URL. It runs entirely in the browser and needs no Python server.

## Original Python game

```powershell
.\dice_game_venv\Scripts\python.exe DicePoker.py
```

## Publish with GitHub Pages

Push the repository, then choose **GitHub Actions** under **Settings → Pages → Build and deployment → Source**. The included workflow publishes `web` after a push.
